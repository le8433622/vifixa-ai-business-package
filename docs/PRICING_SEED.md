## 9. Pricing Rules Engine (Future)

```typescript
interface PricingRule {
  service_id: string
  city?: string           // "hcm", "hanoi", "danang"
  district?: string       // "quan_1", "quan_7"
  time_of_day?: string    // "peak" (7-9h, 17-19h), "off_peak"
  day_of_week?: string    // "weekday", "weekend"
  weather?: string        // "rain", "hot"
  demand_multiplier?: number  // 1.0 - 3.0x
  base_price_adjustment?: number  // VND
}
```

### Dynamic Pricing Examples:
- Sửa máy lạnh mùa nóng (tháng 3-7): +20%
- Giao hàng giờ cao điểm: +30%
